Envie uma mensagem para observar a resposta UDP.
Como funciona o Echo?
  1. 1. Envio: o datagrama sai do seu navegador → ponte HTTP local → socket UDP → servidor Echo em :5000.
  2. 2. Servidor: lê os bytes, registra o IP e a porta de origem e devolve o mesmo datagrama sem alteração.
  3. 3. Resposta: o datagrama volta pelo mesmo caminho e aparece abaixo com bytes, latência e porta efêmera do cliente.

O Echo demonstra que UDP não estabelece conexão: o servidor não mantém estado, apenas responde a quem enviou.

O que é demultiplexação?

Quando um datagrama UDP chega ao computador, o sistema operacional examina o IP de destino e a porta de destino para entregá-lo ao processo correto.

Como Echo (:5000) e Chat (:5001) escutam portas diferentes, o SO consegue distinguir os dois — mesmo que os datagramas cheguem pelo mesmo IP (127.0.0.1).

Já os clientes usam portas efêmeras (temporárias, atribuídas pelo SO) para receber as respostas. Cada cliente tem uma porta única, permitindo que várias conversas ocorram simultaneamente.
